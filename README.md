# Pawfect Clinic Management System 🐾

نظام إدارة العيادات البيطرية المتكامل (Vet Clinic Management System).
تطبيق ويب داخلي مبني بلغة Python وإطار عمل Django، مصمم ليعمل **بدون اتصال بالإنترنت (Offline-first)** عبر الشبكة المحلية (LAN) للعيادات البيطرية، لتنظيم العمليات اليومية وسجلات المرضى والأطباء والمواعيد بكفاءة وموثوقية عالية.

---

## 🌟 الميزات الرئيسية (Key Features)

- **إدارة المربين والعملاء (Owners Management):** تسجيل بيانات مربي الحيوانات ومعلومات الاتصال وسجل الزيارات.
- **إدارة المرضى / الحيوانات (Animals & Patients):** ملف شخصي لكل حيوان، الأنواع، السلالات، تاريخ الميلاد، والحالة الصحية مع ربط بالمالك الأساسي.
- **إدارة المواعيد (Appointments):** جدولة المواعيد وحجز الجلسات مع منع التضارب للمواعيد بين الأطباء (Double-booking prevention).
- **السجلات الطبية السريرية (Clinical Records):** تشخيصات، أعراض، خطط العلاج، والملفات المرفقة (أشعة، تحاليل، إلخ).
- **سجل اللقاحات والتطعيمات (Vaccinations):** متابعة جرعات اللقاحات، تواريخ الاستحقاق والتذكيرات الدورية.
- **نظام التذكيرات (Reminders):** تنبيهات لمواعيد المتابعة والتطعيمات الدورية.
- **الصلاحيات والمستخدمين (Accounts & RBAC):** إدارة المستخدمين (مدير، طبيب بيطري، موظف استقبال) مع تخصيص دقيق للصلاحيات.
- **سجل التدقيق (Audit Logs):** تتبع جميع العمليات والتعديلات لضمان النزاهة والأمان.
- **النسخ الاحتياطي التلقائي والمحلي (Automated Local Backups):** أدوات نسخ احتياطي واستعادة محلية لحماية بيانات العيادة.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Backend:** Python 3.10+, Django 5+
- **Database:** PostgreSQL (أو SQLite للتطوير المحلي)
- **Frontend:** Django Templates, Tailwind CSS, Alpine.js, HTMX
- **Packaging:** PyInstaller (تطبيق تنفيذي مستقل للعيادة)

## 🚀 التثبيت والتشغيل المحلي (Getting Started)

### 1. استنساخ المشروع
```bash
git clone https://github.com/SaaerHamzeh/pawfect-clinic-system.git
cd pawfect-clinic-system
```

### 2. إعداد البيئة الافتراضية
```bash
python -m venv .venv
# على ويندوز:
.venv\Scripts\activate
# على لينكس/ماك:
source .venv/bin/activate
```

### 3. تثبيت المتطلبات
```bash
pip install -r requirements.txt
npm install
npm run build
```

### 4. إعداد ملف البيئة
قم بإنشاء ملف `.env` استناداً إلى `.env.example`:
```bash
cp .env.example .env
```
وقم بتعديل بيانات قاعدة البيانات ومفتاح السر `DJANGO_SECRET_KEY`.

### 5. تهيئة قاعدة البيانات وإنشاء الحساب الرئيسي
```bash
python manage.py migrate
python manage.py createsuperuser
```

### 6. تشغيل خادم التطوير
```bash
python manage.py runserver
```
افتح المتصفح على: `http://127.0.0.1:8000`

## 🔒 الخصوصية والأمان في بيئة العيادة (Offline LAN Deployment)

- النظام مصمم ليعمل بالكامل **بدون اتصال بالإنترنت**.
- إمكانية ربط أجهزة الاستقبال وعيادات الفحص عبر الشبكة المحلية (LAN).
- يتم تخزين جميع المرفقات والبيانات محلياً دون رفع أي بيانات إلى السحابة.
